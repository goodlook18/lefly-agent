# 路线图

[English](../roadmap.md) | 简体中文

本路线图说明 LeFly Agent 在 `v0.1.1` 软件 Alpha 之后的发展方向。它描述预期结果，不给出固定发布日期。随着架构、安全要求和社区反馈变化，优先级可能调整。列在这里的事项不构成交付承诺。

## 当前可用

当前源码 Alpha 提供：

- LeFly Device Protocol v1 和异步 Python SDK；
- Simulator Lite 和内置三维 Web Console；
- 内置五关节预设动作、灯头控制、生命周期状态、虚拟传感器和诊断；
- 确定性文本命令和可选的 LiveKit LLM 工具；
- 可复现的源码导出、干净安装、集成、浏览器、视觉和许可边界检查。

`v0.1.1` 的准确支持范围和已知限制见[兼容性](compatibility.md)。

## 下一步

### 可移植动作链路

用可移植、硬件无关的动作链路替代彼此孤立的内置预设。预期结果包括：

- 带版本的动作格式和归一化五关节运动时间线；
- 面向用户自定义动作的 CSV 导入和校验；
- Simulator Lite 中的确定性播放；
- Console、SDK 和 Agent 客户端共享同一个具名动作入口；
- 为未来实体设备适配器提供明确的执行边界。

只有格式、播放行为和安全限制一起通过验收后，动作链路才会作为受支持的公开功能发布。

### 软件 Alpha 稳定性

- 根据社区实际使用情况改进安装、诊断和错误指引；
- 保持 Protocol v1 变更为增量式，并通过能力声明进行门控；
- 扩展兼容性证据，同时避免夸大未支持的平台；
- 以英文文档为默认版本，并维护主要使用流程的简体中文翻译。

## 后续计划

### LeFly 实体适配器和开发套件

- 为受支持的 LeFly 硬件提供独立发布的 Device Protocol 适配器，不把硬件驱动导入 clean core；
- 对 Simulator 和实体硬件运行相同的协议一致性测试；
- 在声明套件受支持前，发布版本化的兼容性、校准、安全、装配和恢复资料；
- 保持硬件源码、第三方依赖和许可证可独立审计。

当前[硬件预览](hardware-preview.md)只用于探索，不代表已经确定供货或发布日期。

### 语音与近场交互

- 使用现有 Agent 和 SDK 边界增加 LiveKit 语音链路；
- 集成麦克风输入、ASR、TTS、打断和重连行为；
- 支持可配置的触摸、手势和人脸事件响应；
- 在受支持硬件上验证延迟、电机噪声处理、误识别和生命周期状态。

### 教育实验和课程资料

- 优先提供基于 Simulator 的 Device Protocol、SDK、Text Agent、动作、灯光和虚拟传感器实验；
- 增加自定义行为和 Agent 工具的项目式扩展练习；
- 准备教师指南、学生任务单、故障排查和示例项目；
- 只有在适配器、套件和安全边界稳定后，才把学习路径扩展到受支持的实体硬件。

## 探索方向

探索事项需要单独完成设计审批，也可能不会转化为正式功能：

- **视觉交互：** 基于 Camera 感知人物、手势、物体和近场区域，并与注视、动作和眼睛显示屏表情协调；
- **运动智能：** 辅助编舞、动作适配，以及后续超越固定预设的学习式动作生成；
- **音乐律动：** 先通过离线音频分析生成同步舞蹈时间线，再考虑实时生成；
- **交互数据：** 在用户知情同意的前提下建立采集和评估闭环，改进近场交互，同时不把私有数据设为使用项目的前提。

## 路线如何进入开发

路线事项只有在范围、架构边界、验收标准和发布影响经过评审后，才会进入排期。公开仓库发布后，具体工作应关联 GitHub Issues 或 Milestones，方便贡献者区分正在执行的任务和长期方向。
